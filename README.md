# UniDocs

**All Your Documents. One App.**

UniDocs is a modern, lightweight, all-in-one document viewer for Android. It is designed to simplify document viewing by bringing multiple office file formats into a single, intuitive application.

## Key Features

- All-in-one document viewer.
- Microsoft Word document viewing.
- Microsoft Excel spreadsheet viewing.
- Microsoft PowerPoint presentation viewing.
- PDF document reader.
- CSV and text file viewing.
- Clean and modern user interface.
- Lightweight application design.
- Simple document navigation.

## Supported File Formats

| Document Type | File Extensions |
|---|---|
| Word | DOC, DOCX |
| Excel | XLS, XLSX |
| PowerPoint | PPT, PPTX |
| PDF | PDF |
| CSV | CSV |
| Text | TXT |

## Download & Installation

1. Download `UniDocs.apk` from the Releases section.
2. Open the downloaded APK file.
3. Allow installation from unknown sources if prompted.
4. Install and launch UniDocs.
